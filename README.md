# 回合制战棋引擎

纯 Python 标准库实现，仅依赖 pytest 运行测试。

## 规则

- 移动范围：BFS 从起点扩展，消耗按**进入格**地形计算；障碍物完全不可通行；剩余移动力不足以进入的格子不可达。
- 地形叠加：进入格消耗 = 基础地形消耗（`set_terrain`，默认 1）+ 所有附加效果（`add_terrain_effect`）之和，下限为 1。
- 单位阻挡：不能穿过其他单位，也不能停在被占据格；拥有 `can_pass_through` 技能的单位可穿过但不能停留。
- 机会攻击：单位离开敌方威胁格（曼哈顿距离 ≤ 敌方攻击距离）时触发，每个敌方单位每回合最多触发一次，`end_turn` 后重置。
- 攻击范围：始终基于单位当前所在格计算，移动后即基于终点。

## 运行测试

```bash
python -m pytest tests/ -q
```
